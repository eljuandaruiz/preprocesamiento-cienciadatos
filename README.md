# Preprocesamiento de Datos - Casa Mamayema

## Nombre del proyecto
Sistema de preprocesamiento de reservas de habitaciones - Casa Mamayema

## Objetivo
Cargar, limpiar y analizar los datos de reservas de habitaciones para detectar
valores faltantes y obtener estadisticas basicas del dataset.
